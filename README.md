# 📊 Internet Company Customer Churn Analysis

An end-to-end Customer Churn Analysis project focused on identifying churn patterns, understanding customer behavior, and generating actionable business insights using **Python, SQL, and Power BI**.

The project follows a complete analytics workflow:

**Raw Data → Data Cleaning → EDA → SQL Business Analysis → Power BI Dashboard → Business Insights**

---

## 📌 Project Overview

Customer churn is an important business problem for subscription-based and internet service companies because losing existing customers can directly impact revenue and long-term customer value.

The objective of this project is to analyze customer churn patterns across different customer attributes and identify segments that may require greater retention attention.

The analysis covers:

- Customer demographics
- Contract types
- Subscription types
- Payment methods
- Internet services
- Technical support
- Customer tenure
- Monthly charges
- Total charges
- Geographic distribution
- Customer risk segmentation

The project was developed as a practical end-to-end Data Analytics project using Python, MySQL, SQL and Power BI.

---

# 🎯 Business Objectives

The main objectives of this project are:

1. Calculate the overall customer churn rate.
2. Identify customer segments with higher churn rates.
3. Analyze churn across different contract types.
4. Compare churn across subscription plans.
5. Analyze churn patterns by payment method.
6. Compare tenure between churned and retained customers.
7. Analyze geographic differences in customer churn.
8. Investigate the relationship between customer spending and churn.
9. Identify a high-risk customer segment using multiple conditions.
10. Build an interactive Power BI dashboard for business analysis.

---

# 🗂️ Dataset

The dataset contains customer-level information related to an internet/subscription-based company.

### Main attributes

| Column | Description |
|---|---|
| Customer_ID | Unique customer identifier |
| Customer_Name | Customer name |
| Gender | Customer gender |
| Age | Customer age |
| State | Customer state |
| City | Customer city |
| Tenure_Months | Customer tenure in months |
| Subscription_Type | Basic, Standard or Premium |
| Monthly_Charges | Monthly customer charges |
| Total_Charges | Total customer charges |
| Contract_Type | Contract duration |
| Payment_Method | Customer payment method |
| Internet_Service | Internet service type |
| Tech_Support | Whether technical support is available |
| Senior_Citizen | Senior citizen indicator |
| Dependents | Whether customer has dependents |
| Churn | Customer churn status |
| Last_Interaction_Date | Last customer interaction date |
